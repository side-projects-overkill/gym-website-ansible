🚀 Quick Start

Get your website deployed in under 5 minutes:

✅ Prerequisites: Ansible installed, SSH access configured (ssh gym working)

Basic Deployment

1. Test Connection
ansible gym-server -m ping
2. Create HTML File
# Create index.html with your content
echo "<h1>My Website</h1>" > index.html
3. Deploy
ansible-playbook local-deploy-simple.yml
4. Visit Site
# Open in browser:
http://192.168.1.11

📋 Essential Commands

🔄 Website Deployment

Deploy Local File
# With backup (recommended)
ansible-playbook local-deploy-simple.yml

# Quick deploy (no backup)
ansible-playbook local-deploy-simple.yml -e "backup_local=false"
Deploy from Git
# Deploy from repository
ansible-playbook deploy-website.yml

# Deploy specific repo
ansible-playbook deploy-website.yml -e "git_repo_url=https://github.com/user/site.git"

🛠️ System Management

Health Check
# Test connectivity
ansible gym-server -m ping

# Test website
ansible gym-server -m uri -a "url=http://192.168.1.11/ method=GET" -c local
View Logs
# Recent visits
ansible gym-server -m shell -a "tail -10 /var/log/httpd/access_log"

# Server errors
ansible gym-server -m shell -a "tail -10 /var/log/httpd/error_log"
Service Control
# Restart Apache
ansible gym-server -m systemd -a "name=httpd state=restarted"

# Check status
ansible gym-server -m systemd -a "name=httpd"
Backup & Restore
# Create backup
ansible-playbook backup-current.yml

# Emergency restore
ansible-playbook rollback.yml

💡 Real Examples

Personal Blog Setup

Complete Workflow
# 1. Create your blog
cat <<EOF > index.html
<!DOCTYPE html>
<html>
<head><title>My Blog</title></head>
<body>
  <h1>Welcome to My Blog</h1>
  <p>This is my first post!</p>
</body>
</html>
EOF

# 2. Test first
ansible gym-server -m ping

# 3. Deploy
ansible-playbook local-deploy-simple.yml

# 4. Verify
curl -I http://192.168.1.11

# 5. For updates, just edit and redeploy
vim index.html
ansible-playbook local-deploy-simple.yml -e "backup_local=false"

Team Project with Git

Git-Based Workflow
# 1. Set up repository (one time)
git init
git add index.html
git commit -m "Initial site"
git remote add origin https://github.com/team/website.git
git push -u origin main

# 2. Configure deployment (edit inventory.yml)
# Set git_repo_url to your repository

# 3. Deploy from Git
ansible-playbook deploy-website.yml

# 4. Team workflow: anyone can deploy latest changes
git pull origin main
ansible-playbook deploy-website.yml

🚨 Troubleshooting

Connection Problems

Debug Steps
# 1. Test SSH directly
ssh gym

# 2. Check Ansible configuration
ansible-config view

# 3. Verbose connection test
ansible gym-server -m ping -vvv

# 4. List SSH keys
ssh-add -l

Website Not Working

Common Fixes
# Check Apache status
ansible gym-server -m shell -a "systemctl status httpd"

# Restart Apache
ansible gym-server -m systemd -a "name=httpd state=restarted"

# Check file permissions
ansible gym-server -m shell -a "ls -la /var/www/html/"

# Test from server
ansible gym-server -m shell -a "curl -I http://localhost/"

Deployment Issues

Debug Deployment
# Check local file exists
ls -la index.html

# Check server disk space
ansible gym-server -m shell -a "df -h"

# Verbose deployment
ansible-playbook local-deploy-simple.yml -vvv

# Check error logs
ansible gym-server -m shell -a "tail -20 /var/log/httpd/error_log"
